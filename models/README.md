# SENTINEL AI Models

This directory stores trained model weights for the Threat Fusion Engine.

## Files

- `threat_fusion_v1.pt` — PyTorch model weights (generated by `src/ai_engine/train.py`)
- `threat_fusion_v1.onnx` — ONNX export for production inference

## Training

```bash
python -m src.ai_engine.train
```

This generates 500K synthetic samples and trains the multi-modal fusion model.
Output: `/models/threat_fusion_v1.pt`
